## Backup và restore đã chạy

`scripts/backup-server.ps1` được chạy sau khi Paper stop hoàn toàn, không còn writer DB. Bundle riêng `backups/v06-multi-paired-ok` chứa full runtime/world, PostgreSQL custom dump và manifest SHA-256 của 241 file. Trong đó có 109 file world, bao gồm các dimension `cv_sky`, `cv_prison`, player data và dimension vanilla; không chỉ copy region của một world. Manifest UTC `2026-10-10T10:35:19.2927702Z`.

`scripts/restore-server.ps1` xác minh toàn bộ bundle trước khi tạo DB `cv_v06_restored` và thư mục `run-v06-restored`, đổi URL DB trong config bản phục hồi; không ghi đè bản gốc. PostgreSQL restore thành công. Toàn bộ 109 file world khớp checksum trước khi khởi động. 14 bảng schema khớp nội dung JSON được sắp thứ tự, bao gồm migration, operations, ledger, quota, kho/token, profiles, claims và node cooldown; hai file đối chiếu có SHA-256 `85d2c5631039c29f56114000c681595bbf53dcd345cc773d666ee04229a284e1`.

Paper bản phục hồi lên database-ready=true. Cả hai client đăng nhập lại; token TyninWorld `60764711-2a94-433c-8837-a5726ee913dc`, token NPC1 `c630f59b-d5c1-4471-bb72-f39dd45c0327` giữ nguyên UUID/owner. Công trình cobblestone còn nguyên; starter chest không bị dựng lại; quyền đã thu hồi tiếp tục chặn NPC1 phá khối bằng input client. Đối chiếu 14 bảng sau khi hai client reconnect vẫn khớp bản gốc. Cuối phiên server phục hồi và cụm DB thử đều được dừng đúng quy trình.

Guard đã quan sát: backup khi server còn chạy bị từ chối; bundle bị sửa server.properties bị từ chối vì checksum; đích restore đã tồn tại bị từ chối. Hai ca restore bị từ chối không tạo DB mới. Các script không xóa bản backup lỗi hoặc DB restore dở; lỗi được báo để người vận hành kiểm tra.

Bản script cuối được chạy lại end-to-end vào bundle `v06-final-script-bundle`, thư mục riêng `backups/v06-final-script-server`, DB `cv_v06_script_check`: backup/restore 241 file thành công, 14 bảng vẫn khớp. Output trong `v06-backup-final-scripts.txt`; cả hai script cũng qua kiểm tra cú pháp PowerShell. Không chạy lại Java tests vì không thay mã Java; kết quả 36 tests trước đó vẫn là bằng chứng cho cùng JAR.

Bằng chứng: `v06-multi-server.log`, `v06-restored-server.log`, `v06-multi-before-db.txt`, `v06-multi-restored-db.txt`, `v06-multi-restored-after-login-db.txt`, `v06-multi-all-before-db.txt`, `v06-multi-all-restored-db.txt`, `v06-backup-guards.txt`, `v06-paired-backup-manifest.json`. ## Phạm vi chấp nhận

Các ca hai client/PDC/quyền đất và phục hồi sau stop đã đạt trong môi trường thử này. Chưa thử backup nóng, crash giữa commit/lưu world, phục hồi máy khác, đầy đĩa, mạng mất giữa dump hoặc tải cao. Backup cần maintenance window, tắt auto-restart và ngăn mọi writer DB bên ngoài suốt quá trình. Checksum phát hiện thay đổi file so với manifest tin cậy; không thay thế mã hóa hoặc chữ ký backup.
